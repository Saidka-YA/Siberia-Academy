# Подготовка компьютера к занятиям Siberia Academy

Этот гайд состоит из четырёх модулей. Если у тебя Windows, пройди модули 1 и 2. Если Linux уже установлен, переходи от модуля 1 к модулю 3. Модуль 4 пригодится, если что-то пошло не так.

> Перед публикацией преподавателю нужно заменить все поля вида `[ЗАПОЛНИТЬ: …]` и добавить изображения на места пометок `[СКРИНШОТ: …]`.

## Модуль 1. Что мы настраиваем и зачем

На курсе понадобится Linux с заранее подготовленными инструментами. Они нужны для практики по сетям, программированию, анализу файлов и безопасности. Работай с ними только в учебной среде или там, где у тебя есть разрешение.

Подготовить окружение можно двумя способами:

- **Windows:** установи Oracle VirtualBox, скачай готовый образ `.ova` с платформы и импортируй его. Linux запустится в отдельном окне как виртуальный компьютер; переустанавливать Windows не нужно.
- **Linux:** скачай со страницы курса скрипт для своего дистрибутива и запусти его. Он установит инструменты в уже имеющуюся систему.

В подготовленном окружении есть или устанавливаются: GNS3, `ubridge`, `vpcs` и `xterm` для сетевых лабораторных; Wireshark, `tshark`, `tcpdump`, Nmap и сетевые утилиты для анализа трафика; Sleuth Kit, TestDisk, ExifTool, Binwalk, `xxd` и QPDF для анализа файлов; Python, Go, C/C++ и средства разработки; Docker, VS Code, Firefox, Postman, Burp Suite Community, FoxyProxy и XSStrike. Набор дополнительных программ зависит от версии скрипта; если конкретная утилита не появилась, сообщи преподавателю.

**Что понадобится:** стабильный интернет, свободное место для скачанного образа и импортированной виртуальной машины, а также пароль администратора своего компьютера. Точные требования к памяти и месту для учебного образа: `[ЗАПОЛНИТЬ: минимальные требования OVA]`.

## Модуль 2. Windows: от VirtualBox до входа в Linux

### 2.1. Установи Oracle VirtualBox

1. Открой [официальную страницу загрузки VirtualBox](https://www.virtualbox.org/wiki/Downloads).
2. В разделе **VirtualBox Platform Packages** выбери **Windows hosts** и скачай установщик.
3. Запусти скачанный `.exe`. Если Windows запросит разрешение на изменение устройства, проверь издателя и разреши установку.
4. Пройди шаги мастера установки. Если мастер предупредит о кратковременном отключении сети при установке сетевых компонентов, сохрани текущую работу и продолжи.
5. Запусти **Oracle VirtualBox** через меню «Пуск».

### 2.2. Скачай учебный образ

1. Открой страницу курса: `[ЗАПОЛНИТЬ: ссылка или путь на платформе]`.

### 2.3. Импортируй образ

1. В окне VirtualBox нажми **Home → Import**. В другой версии интерфейса это может быть **Файл → Импорт конфигураций**. Можно также дважды щёлкнуть по файлу `.ova` в Проводнике.
2. Выбери скачанный файл `[ЗАПОЛНИТЬ: точное имя файла .ova]`.
3. Проверь имя виртуальной машины и папку, в которой она будет храниться. Убедись, что на диске достаточно места. Остальные параметры оставь как в образе, если преподаватель не дал других значений.
4. Нажми **Finish / Импорт** и дождись окончания. Не закрывай VirtualBox во время импорта.

### 2.4. Запусти систему и войди

1. В списке VirtualBox выбери импортированную машину `[ЗАПОЛНИТЬ: имя ВМ в списке]` и нажми **Start / Запустить**.

## Модуль 3. Linux уже установлен

Этот путь рассчитан на тех, кто уже уверенно пользуется терминалом и знает свой дистрибутив. Скрипты меняют системные пакеты и настройки, поэтому перед запуском прочитай выбранный файл и сохрани важные данные. Нужны интернет, `sudo` и обычная учётная запись пользователя.

1. Узнай свой дистрибутив: `cat /etc/os-release`.
2. Скачай со страницы курса `[ЗАПОЛНИТЬ: ссылка или путь к скриптам на платформе]` подходящий файл:

   | Система | Скрипт |
   | --- | --- |
   | Ubuntu 22.04 / 24.04 / 26.04 | `install-security-toolkit-ubuntu.sh` |
   | Arch Linux x86_64 | `install-security-toolkit-arch.sh` |
   | Fedora Workstation 43 / 44 | `install-security-toolkit-fedora.sh` |

3. Открой терминал в папке со скачанным файлом. Для Ubuntu запусти `sudo bash install-security-toolkit-ubuntu.sh`, для Arch Linux — `sudo bash install-security-toolkit-arch.sh`, для Fedora — `sudo bash install-security-toolkit-fedora.sh`.
4. Дождись сообщения о завершении, прочитай результаты проверки в конце скрипта, затем выйди из сеанса и войди снова. Это нужно для новых групп доступа и путей к инструментам.

Скрипт для Arch Linux сначала полностью обновляет систему через `pacman`. Часть инструментов GNS3 распространяется через AUR. Скрипт попросит проверить сборочные файлы и подтвердить их установку. Если не понимаешь содержимое сборочного файла, попроси помощи преподавателя.

Для других дистрибутивов универсального скрипта здесь нет: согласуй способ установки с преподавателем.

## Модуль 4. Если что-то не получилось (и маленькое послание владельцам Mac)

Сначала запиши **точный текст ошибки**, название системы и шаг, на котором она появилась. Введи текст ошибки в поиск вместе со словами `VirtualBox`, `Arch Linux` или `Fedora` — так обычно быстрее находится решение для твоего случая. Начни с [руководства Oracle VirtualBox](https://docs.oracle.com/en/virtualization/virtualbox/7.2/user/) или документации своего дистрибутива. Если решение требует менять UEFI/BIOS или удалять системные пакеты и ты не уверен в действиях, покажи ошибку преподавателю.

Частые проверки: `.ova` скачался целиком; на диске осталось достаточно места; в VirtualBox выбрана именно импортированная машина; интернет работает; для запуска Linux-скрипта выбран файл под свой дистрибутив. Скриншот ошибки и точная команда помогут получить ответ быстрее.

**А если у тебя Mac:** поздравляем, Unix-подобная система у тебя уже есть. Мы верим в тебя, твой терминал и способность найти инструкцию по своей модели Mac. Если серьёзно: не запускай Linux-скрипты на macOS; ищи установку нужных инструментов для macOS и сверяй требования курса с преподавателем.
